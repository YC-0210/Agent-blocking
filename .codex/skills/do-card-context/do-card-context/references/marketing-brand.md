## 核心價值主張

**一句話**：物理分離創造的承諾感，是純軟體無法複製的。

**機制**：tap 實體卡片的動作無法從同一個螢幕撤銷。這不是一個功能，這就是整個產品。

**儀式感**：物理 tap 創造心理狀態切換。用戶買的不是 App 封鎖，是那個從分心到專注的儀式。

**核心 Tagline**：
> 輕觸卡片，為每個重要時刻建立儀式感，讓一天有了清晰的節奏。

## DOer 身份認同系統

### 核心定義
> DOer 是那種想到就去做、不讓手機偷走自己時間的人。

**三層語意**：
- 「想到就去做」→ 執行力，正向自我認同
- 「不讓手機偷走」→ 主動的，不是被動戒癮
- 「自己的時間」→ 主權感，不是自律感

**核心形象**：有目標、說到做到的行動者。不是戒癮者，不是自律苦行者。

### DOer 對立面

| DOer 是 | DOer 不是 |
|---------|---------|
| 有事情想完成的人 | 覺得自己有手機成癮問題的人 |
| 主動選擇專注的人 | 被迫管理自己的人 |
| 說到做到的行動者 | 一直在計畫但沒有執行的人 |

### 核心句
**「做就對了」** — DO Card 唯一的核心句，不需要其他 slogan

- 來源：爆紅影片結尾旁白 + CTA，已驗證（2487 人留言、150 人加 LINE）
- 使用場景：影片結尾、IG CTA、購買確認、包裝文字
- 原則：不要稀釋成任何變體，原版最強

## 定位框架

### DO Card 是
- 時間主權工具 — 重新掌握自己的注意力
- 儀式感的起點 — 有意識生活的實體錨點
- Premium productivity accessory（像專注版的 Moleskine）

### DO Card 不是
- ❌ 家長管控（這個定位絕對避免）
- ❌ 戒癮工具
- ❌ 強制限制
- ❌ 數位排毒噱頭

### 競品定位

| 競品 | 弱點 | DO Card 的角度 |
|------|------|--------------|
| Unpluq（荷蘭，NFC+訂閱） | 歐洲品牌，無台灣本地化 | 更精緻的 App + 台灣在地化 + Focus Report |
| Brick（$59 一次性 puck） | 純英文，美國市場 | 更豐富的數據，訂閱升級空間 |
| Opal（純 App，$4.3M 融資） | 無實體元件，軟體障礙容易繞過 | 物理承諾層是他們無法複製的 |
| Mindsight（實體封鎖盒） | 過於極端，不便攜 | 輕量摩擦 + 高質感美學 |
| 台灣市場 | 無直接競品 | 藍海，台灣製造 + 繁中 UX + 7-11 到貨 |

**DO Card 四大差異化**：
1. 物理卡片無法從同一螢幕繞過（vs 純 App）
2. 台灣本地化 + 7-ELEVEN 到貨（vs 進口品牌）
3. 儀式感定位而非「管理工具」（情感共鳴）
4. NT$690 單次購買門檻低（vs 訂閱先行）

## 目標受眾

### 主要 Persona：阿翔
- **年齡**：20–28
- **背景**：台大／頂大學生或職場新鮮人，iPhone 用戶（iOS only）
- **痛點**：知道自己在浪費時間，試過 App 計時器，三天內就繞過了
- **洞察**：他們不需要更多功能，他們需要一個物理的承諾時刻
- **動機**：不是對手機使用感到羞恥，而是想成為一個可以專注的人
- **購買觸發**：看到別人用，或讀到「5 個 Early Adopter 有 bug 還買」
- **價格敏感度**：NT$690 是衝動消費區間，只要價值說清楚

### 次要 Persona
- **學生型（16–22）**：滑手機→考試焦慮→更滑手機的循環，需要一個「開始認真」的儀式
- **職場新鮮人（23–30）**：WFH 無法區分工作與放鬆，需要「上班模式開關」
- **自我要求型成人（30–35）**：有消費力，極簡主義，為品質買單

## 文案風格指南

### 語氣
- 平靜、自信、有意圖感
- 同儕對話（不是品牌對用戶說教）
- 賦能：「你決定」「你的節奏」「你掌控」
- 絕對不說教、不醫療感、不家長感
- 用「你」不用「您」

### 語言規則
- 繁中優先，英文次之
- "DO"、"App"、"DO Card" 不翻譯
- 每句話可以獨立讀懂
- 標點：中文段落用全形。！？

### 禁用 vs 建議用詞

| 禁止 | 使用 |
|------|------|
| 戒癮、成癮、上癮 | 建立節奏、找回主權 |
| 管控、控制 | 設定、選擇 |
| 阻止、禁止、封鎖 | 保護、守護、專注模式 |
| 手機成癮 | 注意力分散 |
| 強迫 | 儀式、習慣 |
| 戒手機、少滑、自律 | 做就對了、DOer |
| 我有問題所以需要這個 | 我有目標要完成 |
| 少看了幾小時手機 | 我完成了___ |
| 生產力工具（太 B2B） | 儀式感、主權、節奏、專注時刻 |

### 標題句式（已驗證有效）
- 輕觸卡片，[desired state]
- 一次觸碰，[transformation]
- 不是限制，是 [empowerment frame]
- [Pain point]？DO Card [solution without restriction framing]

### 已驗證文案
- 「重新掌握時間主導權」
- 「給自己一個清晰的開始」
- 「物理的儀式，真實的改變」
- 「不是限制，是選擇」

## UGC / KOL 影片故事框架

給創作者的敘事結構（不能只做開箱或功能介紹）：

```
1. 我有一件很想做的事（論文／創業／學習／運動）
2. 但我一直被手機打斷，做不到
3. 我開始用 DO Card，tap 一下
4. 我完成了___（具體成果）→ 我變成了一個 DOer
```

**關鍵原則**：第四步說「完成了什麼」，不是「少看了幾小時手機」。結果導向，不是行為導向。

### KOL 篩選標準
- Followers：5,000–50,000（微型 KOL）
- 互動率：IG ≥ 3.5%，YouTube ≥ 4%
- 5步篩選：追蹤數 → 互動率 → 內容契合度 → 受眾輪廓 → DM 測試
- 受眾方向：學生、生產力、極簡、科技生活風格
- 排除：遊戲、純娛樂、無生產力切角的生活類

## 圖片生成 Prompt 指引

**產品拍攝方向**：
- 霧黑卡片，橘色 DO logo，信用卡比例
- 打光：戲劇性側光或底光，橘色調
- 背景：深色煙霧幾何光線 OR 純白／灰極簡
- 情緒：質感、有意圖感、輕電影感

**生活風格拍攝方向**：
- 人物 tap 卡片碰手機，表情平靜專注
- 書桌工作環境，乾淨桌面，道具極少
- 避免：手機成癮意象、緊張表情、雜亂場景

**工具**：OpenArt、Midjourney、Runway Gen-3、Pika 2.0、Kling AI
**後製**：中文文字 + URL 在 Canva 或 Figma 中加入
