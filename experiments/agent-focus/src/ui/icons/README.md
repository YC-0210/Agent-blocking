# Bundled app identification artwork

Only exact bundle identifiers from the selected apps are matched. Images are
embedded into the picker HTML as PNG data URLs, so neither opening the picker nor
changing a selection sends identifiers to an icon CDN. No screenshot extraction,
App Store Search API, installed-app inventory upload, or remote URL supplied by a
phone is used.

| Bundle identifier | Catalogue label | Asset source |
| --- | --- | --- |
| `com.burbn.instagram` | Instagram | [Dashboard Icons PNG](https://github.com/homarr-labs/dashboard-icons/blob/main/png/instagram.png) |
| `com.supercell.laser` | Brawl Stars | [Published Brawl Stars Fan Kit mirror, iTunesArtwork@2x.png](https://github.com/ManinderAngural/BrawlStarsOfficial-FanKit/blob/master/logo/iTunesArtwork%402x.png) |

Fetched 2026-11-06; PNG bytes are unchanged. Catalogue artwork can differ from
current seasonal, alternate or tinted installed icons. Unknown bundle IDs use a
placeholder and their identifier, never another app's artwork. Categories and
websites retain separate counts and are not inferred as individual apps.
