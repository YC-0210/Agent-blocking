# Domain Documentation Layout

## CONTEXT.md
- **Location:** repo root (`/CONTEXT.md`)
- **Purpose:** Single-file orientation for agents — what DO Card is, key architecture, active constraints
- **When to read:** Start of every session before touching code
- **When to update:** After any significant architectural decision or scope change

## Architecture Decision Records (ADRs)
- **Location:** `docs/adr/`
- **Format:** One file per decision, named `NNN-short-title.md`
- **When to read:** When working in an area touched by a past decision
- **When to write:** Use `/decision-mapping` skill after any non-obvious technical choice
