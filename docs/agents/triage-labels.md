# Triage Label Vocabulary

| Role | Label | Meaning |
|------|-------|---------|
| Needs evaluation | `needs-triage` | New issue, not yet reviewed by maintainer |
| Waiting on reporter | `needs-info` | Blocked — needs more detail from the person who filed it |
| AFK-ready | `afk-ready` | Fully specced, safe for an AI agent to pick up and implement |
| Human-ready | `human-ready` | Decision or design judgment required before implementation |
| Won't fix | `wont-fix` | Decided against — closed with explanation |
