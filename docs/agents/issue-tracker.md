# Issue Tracker

**Tracker:** GitHub Issues
**Repo:** YC-0210/DO-IOS-Claude-
**CLI:** `gh` (GitHub CLI)

PRs are NOT treated as a request surface — only Issues go into the triage queue.

## How skills use this

- `/to-issues` creates issues with `gh issue create`
- `/triage` reads open issues with `gh issue list` and applies labels
- `/qa` links QA findings back to issues by number
- AFK agents pick up issues labelled `afk-ready`
