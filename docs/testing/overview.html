Why use a second process?

A new database reader in the same process can still depend on memory from the first read. Here, the first process ends. The second must find the saved data and the first process’s record of the new schedule IDs.

This is a database integration check in the test pyramid. It proves the recorded data case, rather than a complete App Store update on a phone.

“Migrate” means change old saved data into the form the current app uses. The second phase cannot start again from a fresh old-data copy. The app and this test use the same database-opening code; an opening error fails the test.
